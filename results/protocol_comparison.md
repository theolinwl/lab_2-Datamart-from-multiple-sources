# Сравнение сетевых протоколов

| Протокол | Типичная задача | Шифрованный вариант | Поддерживается моей сборкой curl |
|---|---|---|---|
| HTTP | Передача веб-страниц и данных между клиентом и сервером | HTTPS | Да |
| HTTPS | Безопасная передача веб-страниц и данных с использованием TLS | HTTPS | Да |
| FTP | Передача файлов между клиентом и сервером | FTPS | Да |
| FTPS | Передача файлов по FTP с защитой соединения с помощью TLS | FTPS | Да |
| SMTP | Отправка электронной почты между почтовыми серверами или от клиента к серверу | SMTPS | Да |
| SMTPS | Передача электронной почты через SMTP с использованием TLS | SMTPS | Да |

## Проверка поддержки

По выводу команды `curl --version` в списке `Protocols` присутствуют `http`, `https`, `ftp`, `ftps`, `smtp` и `smtps`. Следовательно, используемая сборка curl поддерживает все шесть перечисленных протоколов.

Наличие протокола в списке означает поддержку со стороны curl, но не гарантирует доступность конкретного сервера или успешное подключение к нему.
